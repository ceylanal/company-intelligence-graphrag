# Company Intelligence GraphRAG

A hybrid GraphRAG system combining vector search and a knowledge graph for citation-grounded, multi-hop company research.

## Status

🚧 In progress

## Planned Capabilities

- PDF ingestion with page-level metadata
- Vector-search RAG baseline
- Entity and relationship extraction
- Neo4j knowledge graph
- Hybrid graph and vector retrieval
- Citation-grounded answers
- Multi-hop evaluation dataset
- Latency, quality, and cost benchmarks

## Project Structure

This repository is part of a six-project, production-oriented AI engineering portfolio.
